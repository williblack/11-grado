¿Cómo funciona el "Escáner"?

BUSCARV (Búsqueda Vertical) funciona exactamente como el escáner de código de barras de un supermercado. Tú le das un código, él busca de arriba hacia abajo en una lista (Inventario), y cuando lo encuentra, se mueve hacia la derecha para devolverte un dato específico (como el precio o el nombre).

=BUSCARV(¿Qué_busco?, ¿Dónde_lo_busco?, ¿Qué_columna_quiero?, FALSO)

1. Valor_buscado

La celda donde escribes el código (Ej: B3).

2. Matriz_tabla

Toda tu base de datos (Ej: Tabla 'Inventario').

3. Indicador_columnas

El número de columna que tiene el dato a extraer (Ej: 2 para el Nombre).

4. Rango (Ordenado)

¡Regla de Oro! Siempre usar FALSO (o 0) para forzar una coincidencia exacta.

Generación de Base de Datos con IA

Abre tu IA favorita (ChatGPT, Gemini) y cópiale este prompt exacto. El secreto aquí es pedir formato TSV para que Excel lo pegue perfectamente en columnas.

"Genera una tabla de inventario de una tienda de suministros de oficina y tecnología con exactamente 5 columnas: Cod_Art, Nombre_Art, Categoria, Precio_Unit_COP, Stock_Unidades. Incluye exactamente 10 filas de datos con códigos de artículo únicos (ART001 a ART010), nombres realistas, categorías variadas, precios en pesos colombianos entre 12000 y 2500000, y unidades de stock entre 5 y 200. Entrega SOLO la tabla en formato TSV, sin explicaciones, sin markdown. Usa tabulaciones reales como separador."

Copia el resultado de la IA y pégalo en la celda A1 de Excel.

Estructuración Visual

  • Selecciona el rango de datos (A1:E11).
  • Presiona Ctrl + T y acepta para crear Tabla Estructurada.
  • En la pestaña Diseño de tabla, cámbiale el nombre a Inventario.
  • Aplica formato Moneda ($) a los precios y formato Número (sin decimales) al Stock.

Análisis de Agregaciones

En las columnas G, H, I, J (Fila 2) escribe los encabezados y en la fila 3 aplica estas fórmulas para analizar tu negocio:

Valor Total Inventario: =SUMA(D2:D11)
Promedio de Stock: =PROMEDIO(E2:E11)
Cant. Artículos Electrónica: =CONTAR.SI(C2:C11,"Electrónica")
Capital en Papelería: =SUMAR.SI(C2:C11,"Papelería",D2:D11)

Consulta Automatizada con BUSCARV

Crea una nueva hoja llamada Consulta_Articulos. Digita encabezados y en B3 escribe "ART005". Aplica estas fórmulas en la fila 3:

Celda Dato a Extraer Fórmula
C3 Nombre =BUSCARV(B3,Inventario,2,FALSO)
D3 Categoría =BUSCARV(B3,Inventario,3,FALSO)
E3 Precio =BUSCARV(B3,Inventario,4,FALSO)
F3 Stock =BUSCARV(B3,Inventario,5,FALSO)
